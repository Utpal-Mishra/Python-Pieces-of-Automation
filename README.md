# Python Pieces of Automation

A collection of small Python automation experiments and reusable workflows.

## Side Hustle Engine

`side_hustle_engine/` contains an auditable local-business opportunity pipeline designed to reduce repetitive prospecting work without automating spam.

It can:

- discover local businesses through Google Places Text Search (New)
- prioritise businesses where no website is returned
- score opportunities using public demand signals
- generate clearly labelled concept website previews
- prepare a human-review outreach queue
- run as a gated GitHub Actions workflow

See [`side_hustle_engine/README.md`](side_hustle_engine/README.md) for setup, safeguards and commercial workflow.
